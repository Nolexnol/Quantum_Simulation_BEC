# results/

**Nothing in this directory is version-controlled** — everything here is
regenerated by a script, so committing it would only add noise and bulk.

```
results/
├── figures/    PNGs and GIFs, namespaced by dataset (e.g. figures/coarsening/)
└── derived/    intermediate .npz passed from one script to another
```

`derived/` is the handoff point between stages: for example
`run_binary_box_ensemble.py` writes `binary_box_ensemble_part*.npz` here and
`coarsening_scaling_analysis.py` reads them back. It is *not* for anything
measured — measured data lives under `data/raw/`.

Scripts address both through `quantum_sim.config.PATHS`, never by relative
path, so `QUANTUM_SIM_RESULTS_DIR` relocates the whole tree:

```bash
export QUANTUM_SIM_RESULTS_DIR=/tmp/scratch_results
```

Regenerate with `make figures` and `make sim`.
